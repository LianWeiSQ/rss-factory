# Knowledge Hub landing page source

This directory contains a Vue/Vite landing page for the Knowledge Hub distribution. No production domain is configured or claimed. Upstream testimonials and the upstream CNAME were removed; original attribution remains in the footer.

```sh
npm ci
npm run build
```

Published application packages, when available, are linked from [this repository's releases](https://github.com/LianWeiSQ/rss-factory/releases). For product usage and build instructions, see the [main README](../README.md).

The page still reuses upstream illustration assets; historical text inside raster screenshots is not a claim that they show the new distribution's UI.
